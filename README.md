# The Pangasinan Heritage Digital Showcase

## Project Information

**Project Title:** The Pangasinan Heritage Digital Showcase

**Student Name:** Bea Aganon

**Selected Framework:** Next.js

## Project Description

The Pangasinan Heritage Digital Showcase is a web application designed to promote and showcase the cultural, historical, and natural heritage sites of Pangasinan. The website allows users to explore different heritage destinations and view information about each location.

The application is designed using a responsive and mobile-first approach and follows the Atomic Design structure for organizing reusable components.

## Features

- Heritage Sites Showcase
- Search Functionality
- Category Filtering
- Heritage Site Details
- Responsive Design
- Reusable Atomic Design Components

## Atomic Design Structure

### Atoms
Basic reusable components such as buttons.

### Molecules
Components created by combining atoms, including:

- Navigation Item
- Search Form
- Heritage Card

### Organisms
Larger reusable sections composed of molecules and atoms, including:

- Header Navigation
- Heritage Grid
